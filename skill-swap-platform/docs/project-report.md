# SkillSwap Project Report (Demo)

## Problem Statement
Learners want affordable ways to gain new skills, while teachers want recognition. SkillSwap solves this by enabling peer-to-peer skill exchanges using credits instead of money.

## Architecture
- **Frontend**: HTML, CSS, Bootstrap, JS
- **Backend**: Python Flask
- **Database**: SQLite (demo schema provided)

## Workflow
1. User signs up and lists skills to teach/learn.
2. Backend matches complementary skills.
3. Credits are earned by teaching and spent to learn.
4. Sessions are scheduled and feedback collected.
5. Badges awarded for engagement.

## Demo Notes
- Current version is static demo.
- Backend returns sample JSON.
- Database schema is provided for visualization.
