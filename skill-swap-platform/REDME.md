# SkillSwap Frontend Demo

A static, navigable frontend for the Community Skill-Swap Platform. Built with HTML, CSS, Bootstrap, and JavaScript.

## Pages
- `index.html`: Landing page with features and links
- `login.html`: Login form (demo only)
- `signup.html`: Signup form with client-side validation
- `dashboard.html`: Demo dashboard with Chart.js progress chart and credit balance
- `profile.html`: Add/remove skills to teach/learn (demo interactivity)
- `sessions.html`: Calendar UI to select dates and schedule demo sessions
- `feedback.html`: Submit ratings and comments (demo only)

## How to run
- Open `index.html` directly in your browser.
- Navigate using the navbar to explore each page.
- No backend required; all data is sample/demo.

## Tech
- Bootstrap 5 CDN
- Chart.js CDN (on the dashboard page)
- Custom `css/style.css`
- JS modules: `js/main.js`, `js/dashboard.js`, `js/sessions.js`

## Notes
- This is a static demo; no data is persisted.
- Designed to be easily connected to a Python backend later.
